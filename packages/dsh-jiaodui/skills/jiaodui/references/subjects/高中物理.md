# 高中物理校对规范（人读）

v1 唯一落地学科。输入为单元源文 Markdown（`第N题.md` / `单元N.md`）+ `images/` 配图。先判定内容类型，再按对应专项执行；判断由你（agent）做，计算与校验由 `jiaodui calc` 做。产物与闸门见 `references/report-contract.md`，失败自修见 `references/failure-modes.md`。

## 一、第 0 步：判定内容类型
- **题目**：含「已知 / 求 / 解」结构，或选择题选项为数值 / 物理量，或「题目 + 答案 + 解析」「本题考查…」「解析：」。
- **知识**：以定义段 + 公式块为主，无答案字样，含定律表述 / 概念对比 / 实验步骤，目的是讲解而非考查。
- **混合**：既有知识讲解段，又有可区分的独立题目 + 答案结构（如「例1：」「练习：」）。
- 执行顺序：通用检查 → 知识专项 → 题目专项 → 匹配度评估（混合时）。混合内容报告仍只输出一个 `### 标记原文` + 一个 `### 修改原因`。

## 二、通用五项（所有内容类型，强制执行）
1. **错词错字**：错别字、漏字、多字、词不达意；物理术语（如「匀强磁场」「楞次定律」）用字准确。
2. **标点 / 格式**：标点误用、换行错误、题干编号与选项编号不一致。
3. **学科符号规范**：公式排版、希腊字母、SI 单位符号、矢量符号（箭头或加粗）、上下标正确。
4. **图片内容**（含配图时必做）：受力图 / 电路图 / v-t 图 / 实验装置图是否与题干描述一致；图的本身是否正确（力的方向、电路连接、坐标轴与刻度标注）。
   - **透明底线稿先合成白底再判读**：本流程 PNG 多为透明底黑线稿（实测 alpha=0 像素占 93–95%），直接读图会呈现空白。先按白底合成（转 RGB 时以白色填充）再判断；把「透明图看起来空白」当成读图失败会误判。
   - **读不到图即环境不合格**：完成白底合成后仍读不到图，回报失败，不得跳过。
5. **合规性**：敏感词、敏感人物、不良价值导向（暴力 / 歧视 / 封建迷信 / 历史虚无主义等）→ 标记并说明理由。

## 三、物理专项
### 3.1 题目专项
1. **题干严谨性**：情景描述清晰、已知条件完整、已知量 / 未知量一致、无隐含不合理假设、无歧义。
2. **解析自洽**：题目 → 答案 → 详解三者一致；详解每一步能由前一步与已知条件推出，无跳步到错误结论。
3. **计算必须实算**：所有数值与公式结论用 `jiaodui calc` 校验，**不得心算 / 估算 / 凭印象**（见第四节）。
4. **答案校验与量纲**：用 `calc dimensional` 检查等号两侧量纲一致；所有数值结论经工具实算确认。
5. **独立解题**：v1 **冻结不启用**（旧流程的 `independent_solve` 不在新契约内），答案对错的防线是「实算 + 人工抽检」，不要假装调用。

### 3.2 知识专项
1. **概念 / 定义准确性**：表述严谨、定义完整、术语规范。
2. **公式正确性**：符号、上下标、系数正确；适用条件注明；关键公式用 `calc formula` / `calc dimensional` 做量纲或代入验证。
3. **定律 / 定理表述**：内容完整准确，适用范围说明正确（如动量守恒的条件）。
4. **示例恰当性**：讲解中的示例能否恰当展示概念 / 公式用法，数值是否合理。

### 3.3 混合专项（知识-题目匹配度）
公式覆盖（例题公式是否在前文出现并定义）、难度对等（不要讲完定义就上竞赛题）、情景一致、推导可行（无需引入讲解未覆盖的新概念）。

## 四、calc 验算习惯（强制）
- 数值求值：`jiaodui calc evaluate --param expression="sqrt(u**2 + 2*a*s)" --param 'substitutions={"u": 0, "a": 2, "s": 9}'`
- 方程 / 方程组：`jiaodui calc solve --param 'equations=["x**2 - 4 = 0"]' --param 'variables=["x"]'`
- 物理公式解目标量：`jiaodui calc formula --param "formula=v = u + a*t" --param solve_for=a --param 'substitutions={"v": 20, "u": 0, "t": 5}'`
- 量纲分析：`jiaodui calc dimensional --param "expression=F = m * a" --param 'unit_definitions={"F": "newton", "m": "kilogram", "a": "meter/second**2"}'`（**必须在 `unit_definitions` 中声明表达式里每个符号的单位**，未声明的符号会被拒绝；无量纲写 `dimensionless`；歧义符号给候选列表，如 `{"V": ["meter/second", "meter**3"]}`）
- 等价验证：`jiaodui calc equality --param 'expression_a="sin(x)**2 + cos(x)**2"' --param 'expression_b="1"'`（字符串参数要写成带引号的 JSON，如 `"1"`；否则 `1` 会被解析成整数而报类型错误）
- 向量：`jiaodui calc vector_ops --param vector_operation=dot --param "vec_a=[1, 2]" --param "vec_b=[3, 4]"`
- 磁场偏转轨迹：`jiaodui calc circle_from_two_points --param 'entry_point=["1.5","1"]' --param "velocity_direction=[3, 4]" --param 'impact_point=["0","-1.5"]' --param "impact_normal=[0, 1]"`（v1 只验证数值坐标；含符号的坐标可能报错，遇错先代入数值再算）
- **符号白名单与浮点容差**：`I` 不当作虚数单位、`S` 不当作 sympy 注册器、`alpha` / `beta` 不当作常数；比较结果用容差而非严格相等。结果只取数值结论，**不要粘贴工具原始输出**到报告。
- 工具返回 `success=false` 或明显不合理（量纲错、超物理边界）时，先怀疑调用参数，再怀疑题目；不得直接采信。

## 五、常见错误类型（重点扫描）
- 单位：漏写单位、单位换算错（cm↔m、km/h↔m/s）、非 SI 单位混用、单位与量纲不一致。
- 矢量：该有方向 / 正负号的量（速度、加速度、力、动量、场强）漏方向或正负；标量与矢量混用。
- 符号：同一符号在不同题中含义冲突未说明；下标错（`v_0` / `v_t`）；`g` 取值未说明（9.8 或 10）。
- 有效数字与近似：不合理保留位数；题设精度与答案精度不匹配。
- 公式：漏系数（如动能 `1/2 m v^2`）、适用条件（如匀变速公式用于非匀变速）、正负号约定（如重力势能参考面）。
- 图像：v-t 图的斜率 / 面积含义、坐标轴单位、交点与拐点物理意义；图与题干数据不符。
- 电路：串并联判断、电表接法、滑动变阻器接法、方向与极性。

## 六、易错题型（重点验算）
- **多过程 / 多状态**：先加速后匀速、先碰撞后分离、周期性往复。
- **电磁场 / 电磁感应**：带电粒子偏转、圆周运动半径与周期、法拉第电磁感应、楞次定律方向。
- **能量 / 动量**：守恒条件判断、碰撞类型、机械能损失、功与能转化。
- **复杂受力**：3 个力以上、非共点力、力矩平衡、斜面 / 连接体 / 传送带。
- 上述题型一律先实算、再下结论；拿不准就如实标注，不臆断。
