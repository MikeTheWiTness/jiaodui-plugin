# 固定读图探针（主 agent 使用）

## 资源与时机

- 使用当前加载 skill 目录内的 `assets/vision-probe.png`（预渲染白底 PNG）。定位基于该 SKILL.md 的实际安装路径，解析成绝对路径，不以会话 cwd 猜包位置。独立 skill 与 DSH bundle 都带相同资源。
- `assets/vision-probe.svg` 是绘图源，`assets/vision-probe-transparent.png` 是透明版本，均供维护或排查。正式探针读白底 PNG，不要求读图工具支持 SVG，也不要求现场安装 SVG 渲染器、寻找教材图片或合成白底。
- 每个新会话在首次校对派发前验证一次；同一会话、相同子 agent 模型及工具配置的后续材料可复用本次成功结果，无须逐文件或逐单元重复。模型、工具权限或环境改变后重新验证；不将旧会话记录冒充本次验证。
- 探针成功仅证明本地 PNG 视觉调用可用。实际材料中的透明线稿仍须按需白底合成后读取；不得用探针代替真实题图检查。

## 派发模板（不包含答案）

主 agent 先将下面的 `<图片绝对路径>` 替换为实际白底 PNG 路径，再发给一个干净上下文的子 agent。不要把本参考文件、SVG 源码、下方验收答案或主 agent 对图的描述放入输入包。

> 这是本地图片读取能力探针。请先查看你当前可用的图片读取工具参数定义，再通过该工具实际打开 `<图片绝对路径>`。描述主要物体、颜色、顶部特征，以及底部小图形的形状、颜色和数量。不根据文件名推测，不读取 SVG/源码或答案文件，不用 OCR、像素统计或脚本分类代替视觉读取。回传一行观察摘要及读图工具是否成功；只有路径、文件存在或尺寸不算读图成功。若参数校验失败，按工具 schema 修正参数后重试；仍不能读取时如实返回错误，不猜内容。

DSH 的 `read_image` 当前使用 `file_path`，例如 `{"file_path":"<图片绝对路径>"}`，不要传 `path`。其他宿主以当前工具 schema 为准，不能把这个参数名硬套到所有工具。主 agent 应把已核对的本宿主参数示例一并传给子 agent。

## 验收（仅供主 agent，不下发给探针子 agent）

图中为一个红色苹果，顶部有棕色果梗、一片朝右的绿色叶子，下方横排三个蓝色圆点，背景白色。语义相符即可，不要求逐字一致；必须结合成功的图片工具返回和实际观察，不能只凭“读图成功”四字放行。

## 调用失败的处理

- `missing required property` / `invalid arguments`：属于调用格式错误，尚未检验视觉能力。检查工具 schema，修正后最多重试 2 次；比如 DSH 将 `path` 改为 `file_path`。若用户明确要求遇到任何错误立即停止，按用户要求停下并说明尚未完成视觉验证。
- 文件找不到：检查当前 skill 安装路径与随包资源；不要转而在教材里碰运气，也不创建随机命名的读图探针目录。
- 工具缺失、不返回图片内容、模型无法识别或结果明显不符：不能认定通过。有限修正后仍失败才按 D14 停止校对，准确区分“调用未成功”和“视觉能力未确认”，保留完整错误。
- 正常探针只读取随包图片并返回观察摘要，不生成校对产物；不在插件安装目录写入文件。子 agent 的单元落盘能力按原有流程单独核实。
