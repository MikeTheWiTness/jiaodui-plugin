## 3. 真实语料闸门（双向契约）

对旧仓冻结语料 `output/拆题结果/2026年7月21日高中物理作业`（18 单元，只读）运行：

```bash
.venv/bin/jiaodui status "<旧仓>/output/拆题结果/2026年7月21日高中物理作业" --json
```

结果：**已完成 11 / 已交付未过校验 7**，逐份标注在 `tests/test_legacy_corpus.py`。

> 该数字在审查修复后由 16/2 → 12/6 → 10/8 → 11/7：unknown 只豁免「吸收片段落在
> 源文**真实 `$...$` 公式区间内**」的差异（先用 `scan_math_spans` 标出真正的公式区间）；
> 段落按顺序一一对齐（未匹配源文段判缺段、未匹配报告段判多段/重段）。
> 第18题原被「必须整体包裹公式」的过严规则误拒，改为区间内局部豁免后正确通过。

| 单元 | 拒绝原因 | 判定 |
| --- | --- | --- |
| 第5题 | 空操作（原文 == 改为） | 真实缺陷，PRD §5.2 要求拒绝 |
| 第7题 | 未标记正文被改动（`mgh` → `$mgh$`；图片宽度浮点被截断） | 改变未标记正文，拒绝 |
| 第10/13/15/17题 | 标记切断 `$...$` 公式，装饰美元落在标记字段之外 | 字段外差异，拒绝 |
| 第3题 | unknown 公式字段无法与源文段落对齐（缺段/多段） | 未通过全文比对，拒绝 |
| 第18题 | （修复后）unknown 差异经复核全部落在源文真实公式区间内 | 合法局部公式标记，通过 |

> 复现时若语料不在默认并列目录，设 `JIAODUI_LEGACY_CORPUS` 指向旧仓 `output`；不在位则整文件 skip。

该结果同时说明闸门不是「一律拒绝」：图片题、公式题、答案详解题均被接受。

## 4. 已知偏差与未移植项

- **matplotlib 缺失**：公式 PNG 兜底不渲染，按可见高亮 + 文字建议兜底；生成后复核仍要求缺失=0。
- **classics 后置**：古籍检索未进 v1。
- **未移植（非 v1）**：`fix_latex_escapes`、`clean_intent_markers`、`docx_format_enhancer` 的 strip/generate_clean_md、`smart_split`（Python 调模型，交宿主 agent）。
- **图片属性浮点差异**：报告抄录图片宽度时精度截断会被判为「改变未标记正文」。当前从严；若实测噪声过大，再把「图片属性浮点差异」列入预列明装饰差异。
- `calc circle_from_two_points` 目前仅数值坐标可用（符号坐标受 sympy 关系判断限制），已在 references 注明。

## 7. 环境备注（macOS 代码签名）

pip 安装的 `lxml` 等编译扩展与 DSH 签名 Python 团队号不一致，会 `dlopen` 失败。
故开发 venv 使用 `--system-site-packages` 复用宿主运行时的 lxml/Pillow/python-docx，只 pip 安装纯 Python 的 sympy/pytest。
