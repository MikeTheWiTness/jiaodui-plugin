## 1. 报告总数、来源分布与去重

### 1.1 关键发现：PRD 的 364 来自 glob 跟随软链

Python 的 `glob.glob(root/**/_校对报告.md, recursive=True)` 中 `**` **会跟随目录软链**。
旧仓 `output/校对PDF/第N题` 共 18 个软链指向 `output/拆题结果/...`，于是同 18 份报告被数两遍：

| 口径 | 文件数 | 说明 |
| --- | ---: | --- |
| 物理文件 / 不跟随软链（`pathlib.rglob`） | 356 | 真实文件，= 单元 346 + 整卷 10 |
| glob / 跟随软链（PRD 口径） | 374 | = 356 + 18 个软链重复 |
| PRD 记 | 364 | 与我们用 glob 复算的 364 份单元报告完全一致 |

- `_校对报告.md`（单元报告，精确名）：glob 跟随软链 = 364；不跟随软链 = 346
- `*_校对报告.md`（含 `output/校对报告/` 的整卷报告）：glob = 374；不跟随 = 356
- 去重规则：按文件原始字节的 sha256 分组，同哈希只留路径最短的一份作为代表
  - 精确名集合去重后：跟随软链 274；不跟随软链 274
  - 全部报告去重后：**284**
- 结论：PRD 的「364 份报告」实为含 18 个软链重复的计数；distinct 物理文件 356、内容去重 284。
